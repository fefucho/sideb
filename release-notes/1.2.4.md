# Side B 1.2.4

This patch fixes scroll volume adjustment on Windows when the volume percentage appears but the level stays unchanged. Side B remains in beta.

## Windows

- Fixed a browser timer error in the volume indicator that interrupted wheel handling before the audio command was sent.
- Verified volume changes in both directions on the large artwork and open volume control, including the percentage timeout.
- Preserved the existing volume scale, slider, mute, scroll sensitivity and input regions.
- Includes a regression test for native browser timer binding. The corrected local build was also tested and confirmed working by the affected user.

## macOS

- No additional UI or audio changes. Rebuilt as 1.2.4 to keep the platform downloads on the same release.

## Downloads

- **macOS:** `SideB-macOS.zip` — Apple Silicon, macOS 15 or later; ad-hoc signed, not Developer ID notarized.
- **Windows installer:** `SideB-Windows-x64-setup.exe` — 64-bit Windows with WebView2.
- **Windows portable:** `SideB-windows-x64.zip` — extract the whole archive and keep its executable, libmpv, Vulkan runtime and license together.
- SHA-256 checksum files are included for both platforms.
