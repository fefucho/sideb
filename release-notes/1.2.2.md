# Side B 1.2.2

This patch fixes page layout on macOS and mouse-wheel volume adjustment on Windows. Side B remains in beta.

## macOS

- Explore now uses the same page width and title alignment as Home. Removed the small duplicate heading and introductory text.
- Library and Search headings, fields and filters scroll together with their content.
- Kept large song lists and library collections virtualized, with focus and search suggestions preserved.
- Kept the error and Retry control visible when a library song filter has no matches.

## Windows

- Fixed small or slow wheel movements showing the volume percentage without changing the volume. Partial movements now accumulate while staying on the same eligible artwork or open volume control.
- Leaving the volume surface clears pending movement even after the percentage feedback has disappeared.
- Slider adjustment and the existing volume scale are preserved.

## Downloads

- **macOS:** `SideB-macOS.zip` — Apple Silicon, macOS 15 or later; ad-hoc signed, not Developer ID notarized.
- **Windows installer:** `SideB-Windows-x64-setup.exe` — 64-bit Windows with WebView2.
- **Windows portable:** `SideB-windows-x64.zip` — extract the whole archive and keep the executable, libmpv, Vulkan runtime and license together.
- SHA-256 checksum files are included for both platforms.
