# Side B 1.2.3

This patch fixes wheel volume adjustment on Windows when the input includes sideways movement. Side B remains in beta.

## Windows

- Fixed the volume percentage appearing without a volume change on the large artwork and open volume control. A sideways or zero sample no longer cancels an already active vertical volume gesture.
- Kept partial vertical movement so later vertical samples can complete a volume step. Sideways samples do not change volume themselves.
- Preserved slider adjustment, the existing volume scale and the guards for panels, dialogs, dragging and leaving the volume surface.
- Added regression coverage using recorded Windows input from the affected app.

## macOS

- Includes the page width and scrolling header improvements from 1.2.2, with no additional UI or audio changes in this patch.
- Rebuilt as 1.2.3 to keep both platform downloads on the same release.

## Downloads

- **macOS:** `SideB-macOS.zip` — Apple Silicon, macOS 15 or later; ad-hoc signed, not Developer ID notarized.
- **Windows installer:** `SideB-Windows-x64-setup.exe` — 64-bit Windows with WebView2.
- **Windows portable:** `SideB-windows-x64.zip` — extract the whole archive and keep the executable, libmpv, Vulkan runtime and license together.
- SHA-256 checksum files are included for both platforms.

Version **1.2.3**, public build **16**. Packages are published together after native build, test and checksum verification.
