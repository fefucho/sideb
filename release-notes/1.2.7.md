# Side B 1.2.7 — Lyrics Update

Word-synced lyrics, a unified fullscreen lyrics experience, and animated artwork arrive on macOS and Windows. Side B remains in beta.

## Lyrics

- Word-by-word highlighting when the provider supplies word timestamps, with continuous progress across wrapped words and support for multiple voices and translations.
- Original and new lyrics share text size, Karaoke/Reading modes, automatic following and manual scrolling. Timing, translations and word motion are available in the lyrics options menu.
- Keeps classic lyrics available while richer lyrics load. Songs with line-only timing continue to highlight by phrase; word timings are never invented.
- Windows fixes duplicated moving words, anchors wrapped fragments to their own visual line, and preserves the soft blur at the left edge of contextual lyrics.
- Clicking a timed line coordinates seeking with the current track and playback state.

## Fullscreen and Windows typography

- Animated album artwork when available, with local caching and lifecycle handling for pause, background visibility, power saving and cache clearing.
- Windows now bundles Inter locally, including normal and italic variable fonts, for consistent typography without downloading fonts at runtime.

## Downloads

- **macOS:** `SideB-macOS.zip` — Apple Silicon, macOS 15 or later; ad-hoc signed, not notarized.
- **Windows installer:** `SideB-Windows-x64-setup.exe` — 64-bit Windows with WebView2.
- **Windows portable:** `SideB-windows-x64.zip` — extract and keep the executable, DLLs and license together.
- SHA-256 checksum files are included for both platforms.

Version **1.2.7**, public build **20**. Both native builds and package checksums must pass before publication. Provider availability, audible synchronization, performance and interactive installation are not certified by automated tests.
