# Side B 1.2.5

This update refines Windows buttons and makes Like, Save and artist subscriptions respond immediately. Side B remains in beta.

## Windows

- Softer button borders, subtle depth and a clearer primary action, with consistent vector icons for playback and library actions.
- Likes and library changes update their visible state immediately while the server confirms the request. Rejected changes restore the previous state and show an error.
- Background library loading no longer queues simple account actions behind long catalog requests. Loading older likes no longer disables unrelated hearts.
- Save and subscription buttons keep their labels and icons visible during confirmation. Sidebar and library refreshes continue in the background after the action completes.
- Simple account actions have a 15-second confirmation budget, including queueing. An unconfirmed request shows an error and releases the control; it is not retried automatically.
- Preserves the Windows scroll-volume fix delivered in 1.2.4.

## macOS

- No additional UI or audio changes. Rebuilt as 1.2.5 to keep both platform downloads on the same release.

## Downloads

- **macOS:** `SideB-macOS.zip` — Apple Silicon, macOS 15 or later; ad-hoc signed, not Developer ID notarized.
- **Windows installer:** `SideB-Windows-x64-setup.exe` — 64-bit Windows with WebView2.
- **Windows portable:** `SideB-windows-x64.zip` — extract the whole archive and keep the executable, libmpv, Vulkan runtime and license together.
- SHA-256 checksum files are included for both platforms.

Version **1.2.5**, public build **18**. Native checks and package hashes are verified before publication. Physical account latency, audio and interactive installation are not certified by automated checks.
