# Side B 1.2.6

The new collection sidebar is now included on both Windows and macOS. Side B remains in beta.

## Sidebar and appearance

- Fixed vertical navigation for Home, Library, Explore and Search, with Likes and History together.
- A scrollable collection with list and grid views. Switch directly beside Your collection, or use Settings → Appearance → Collection view. Both controls share the same saved preference.
- The expanded sidebar is 253 pixels/points wide, with clearer text and selection. Windows keeps its compact rail and navigation actions.
- Settings → Appearance → Home background offers artwork colors or a flat #211E21 background. This preference is saved per installation; collection artwork backgrounds remain available.
- Preserves library tabs, selection, account controls, keyboard access and context menus. macOS search selection takes priority over the Explore page it came from.

## Previous fixes included

- Keeps the Windows button polish and immediate Like/Save feedback from 1.2.5.
- Includes the latest Windows collection header/filter alignment, Explore layout and native cipher runtime integration from GitHub.
- Preserves the scroll-volume fix from 1.2.4.

## Downloads

- **macOS:** `SideB-macOS.zip` — Apple Silicon, macOS 15 or later; ad-hoc signed, not notarized.
- **Windows installer:** `SideB-Windows-x64-setup.exe` — 64-bit Windows with WebView2.
- **Windows portable:** `SideB-windows-x64.zip` — extract all runtime files together.
- SHA-256 checksum files are included for both platforms.
