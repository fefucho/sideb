# Side B 1.5.2

Spotify Jam matching fix on Windows. Side B remains in beta.

## Spotify Jam

- **No more false "no equivalent in YouTube Music":** in large Jams (more than 60 tracks not yet cached by Spotify) the first update arrives without track titles. Those tracks used to be marked as having no equivalent for the whole session. They now stay on "Searching…" until the titles arrive and are matched then.
- **Best match first:** a Jam track is now matched to the top YouTube Music result even when the confidence is low; "no equivalent" only appears when the search returns nothing. If a version is wrong, use "choose another version".
