# README screenshots

Use current screenshots of the native apps here. The first pair should show Home and fullscreen playback; add one lyrics/Genius view if it explains more than the text does.

Keep the app's proportions, choose a readable window size, and avoid debug controls, old bug reports, private playlist names, account details, or desktop notifications. Identify the platform in each caption. QA browser fixtures are useful for tests, but shouldn't be presented as native app screenshots.

Suggested names: `macos-home.png`, `macos-fullscreen.png`, `windows-home.png`, `windows-fullscreen.png`. Add the selected images to the root README beneath Design. No empty image links are published while these captures are pending.
